# הזמנה לחתונה + אישורי הגעה + לוח ניהול · Wedding invitation, RSVP & dashboard

אתר אינטרנט קטן ומהיר (לא אפליקציה שמתקינים) שהאורחים פותחים מקישור בטלפון: רואים את ההזמנה, מאשרים הגעה ומספר אורחים בשתי לחיצות, ומשתפים בוואטסאפ, בטלגרם וב-SMS.
כל מה שהם עושים נשמר בגיליון Google Sheets שלכם ומוצג בלוח ניהול מסודר, במחשב ובטלפון. **הכול בעברית ובאנגלית.**

| | |
|---|---|
| `index.html` | ההזמנה לאורחים (עברית, עם כפתור מעבר לאנגלית) |
| `en.html` | אותה הזמנה באנגלית, עם תצוגה מקדימה באנגלית בוואטסאפ. נוצר אוטומטית מ-`index.html`, אין צורך לערוך |
| `admin.html` | לוח הניהול (מוגן בסיסמה, בעברית ובאנגלית) |
| `config.js` | **כל הפרטים שלכם**: שמות, תאריך, מקום, נוסח ההודעות, בשתי השפות |
| `invitation.pdf` | **ההזמנה שלכם**: מחליפים את הקובץ הזה |
| `js/i18n.js` | כל הטקסטים של הממשק בעברית ובאנגלית |
| `backend/Code.gs` | הקוד שמחבר את האתר לגיליון Google Sheets |
| `tools/build.mjs` | הופך את ה-PDF לתמונות חדות ולתצוגה מקדימה לוואטסאפ, ויוצר את `en.html` (רץ אוטומטית) |

## מה יש באתר

**לאורחים**
- ההזמנה מוצגת מיד כתמונה חדה, גם בטלפון ישן. לחיצה פותחת אותה במסך מלא עם הגדלה (כפתורים או הקשה כפולה). אפשר גם להוריד את ה-PDF.
- אישור הגעה: מגיעים / עוד לא בטוח / לא נוכל, שם, מספר אורחים עם כפתורי פלוס ומינוס, טלפון וברכה לזוג (שני האחרונים לא חובה). אפשר לחזור ולשנות את התשובה.
- ספירה לאחור, תאריך עברי, סדר הערב, Waze ו-Google Maps, הוספה ליומן (Google, אייפון ו-Outlook).
- שיתוף בוואטסאפ, בטלגרם, ב-SMS, העתקת קישור, ושיתוף מובנה של הטלפון.
- כשהקישור נשלח בוואטסאפ או בטלגרם מופיעה תצוגה מקדימה יפה של ההזמנה.

**שתי שפות**
- בפינה העליונה של ההזמנה ושל לוח הניהול יש כפתור **EN / עב**. כל הממשק מתחלף, כולל כיוון הכתיבה, התאריכים והתאריך העברי, והבחירה נשמרת.
- הקישור לאורחים דוברי אנגלית הוא `en.html`, וגם התצוגה המקדימה שלו בוואטסאפ באנגלית.
- לכל מוזמן ברשימה בוחרים שפה, והקישור האישי וההודעה נשלחים אליו בשפה שלו.
- יש לכם גם הזמנה באנגלית? שימו את הקובץ בתיקייה וכתבו את שמו ב-`config.js` (`invitationPdf.en`). אחרת האורחים באנגלית יראו את אותה הזמנה.

**לכם, בלוח הניהול**
- **סקירה**: כמה אורחים אישרו (ומתוך כמה הוזמנו), אולי ולא מגיעים, מי טרם ענה, מבקרים וכניסות, גרף אישורים לאורך זמן, מבקרים ביום, מאיפה הגיעו (וואטסאפ, טלגרם, SMS, QR), חלוקה לפי צד, הברכות האחרונות, והפעילות האחרונה.
- **אישורים**: טבלה עם חיפוש, סינון ומיון, הוספה ידנית (למי שענה בטלפון), עריכה ומחיקה, ייצוא לאקסל והדפסה.
- **מוזמנים**: רשימת מוזמנים (ייבוא בהדבקה מאקסל), קישור אישי לכל מוזמן בוואטסאפ, ב-SMS או בטלגרם, ומעקב: טרם נשלח, נשלח, צפו או ענו. ב**שליחה ברצף** עוברים על כל מי שעוד לא קיבל הזמנה, אחד אחרי השני.
- **שיתוף**: הקישור הכללי, עריכת נוסח ההודעה, תצוגה של איך זה ייראה בוואטסאפ, וקוד QR להורדה.
- **פעילות**: כל צפייה, פתיחה, שיתוף ואישור, עם ייצוא.
- מצב כהה, ריענון אוטומטי כל דקה, ובטלפון תפריט תחתון.

כל עוד הגיליון לא מחובר, האתר עובד ב**מצב הדגמה**: הכול פועל, אבל הנתונים נשמרים רק בדפדפן שלכם. בלוח הניהול יש כפתור "מילוי בנתוני דוגמה" כדי לראות איך הלוח נראה כשהוא מלא.

## הפעלה — 3 שלבים

### 1. הפרטים וההזמנה שלכם

1. ב-`config.js` עדכנו את השמות, התאריך והשעה, המקום, סדר הערב ותאריך היעד לאישורים. כל טקסט שמופיע לאורחים כתוב פעמיים, `he` לעברית ו-`en` לאנגלית. ב-`defaultLang` קובעים באיזו שפה האתר נפתח.
2. החליפו את `invitation.pdf` בהזמנה שלכם, באותו שם קובץ.

אפשר לעשות את זה ישירות באתר של GitHub: נכנסים לתיקייה `wedding`, ואז **Add file → Upload files** כדי להעלות PDF, או לוחצים על `config.js` ועל העיפרון כדי לערוך.

### 2. חיבור לגיליון Google Sheets (כ-5 דקות, פעם אחת)

1. פתחו [גיליון חדש](https://sheets.new) ותנו לו שם, למשל "החתונה שלנו".
2. בתפריט: **תוספים (Extensions) → Apps Script**.
3. מחקו את הקוד שמופיע שם, והדביקו במקומו את כל התוכן של `backend/Code.gs`.
4. בשורה `const ADMIN_PASSWORD = 'change-me';` החליפו את `change-me` בסיסמה שתבחרו ללוח הניהול. שמרו (Ctrl+S).
5. למעלה בחרו את הפונקציה **setup** ולחצו **הפעלה (Run)**. Google תבקש אישור הרשאה: **Review permissions**, בוחרים את החשבון שלכם, ואז **Advanced → Go to … (unsafe) → Allow**. זה הקוד שלכם, והוא ניגש רק לגיליון הזה. בגיליון ייפתחו שלוש לשוניות: אישורי הגעה, מוזמנים ופעילות.
6. **פריסה (Deploy) → פריסה חדשה (New deployment)**. ליד "Select type" לוחצים על גלגל השיניים ובוחרים **Web app**, ומגדירים:
   - Execute as: **Me**
   - Who has access: **Anyone**

   לוחצים **Deploy**.
7. העתיקו את ה-**Web app URL** (הכתובת שמסתיימת ב-`/exec`) והדביקו אותה ב-`config.js`:
   ```js
   backendUrl: 'https://script.google.com/macros/s/……/exec',
   ```

> שיניתם משהו ב-`Code.gs`, למשל את הסיסמה? צריך לפרוס מחדש: **Deploy → Manage deployments**, עיפרון, ב-Version בוחרים **New version**, ואז **Deploy**. הכתובת לא משתנה.

### 3. פרסום האתר (GitHub Pages, בחינם)

1. ב-GitHub נכנסים ל-**Settings → Pages**, ותחת **Build and deployment → Source** בוחרים **GitHub Actions**. עושים את זה פעם אחת.
2. ממזגים את השינויים לענף הראשי של הריפו (Pull request → Merge).

מכאן, כל שינוי בתיקייה `wedding` מתפרסם לבד תוך דקה-שתיים (אפשר לעקוב בלשונית **Actions**). הכתובות:

- הזמנה: `https://tuvyanoam-code.github.io/---/`
- הזמנה באנגלית: `https://tuvyanoam-code.github.io/---/en.html`
- ניהול: `https://tuvyanoam-code.github.io/---/admin.html`

את התמונות מה-PDF ואת התצוגה המקדימה לוואטסאפ הפרסום מייצר אוטומטית, כך שמספיק להחליף את `invitation.pdf`.

> מעדיפים כתובת אחרת, למשל דומיין משלכם? הגדירו אותו ב-Settings → Pages → Custom domain, ועדכנו את `siteUrl` ב-`config.js`.

## שימוש יומיומי

- **שליחה כללית**: בלשונית **שיתוף** לוחצים וואטסאפ, טלגרם או SMS, ושולחים לקבוצה או לאנשי קשר.
- **שליחה אישית (מומלץ)**: בלשונית **מוזמנים** מייבאים את הרשימה מאקסל, בשורות של "שם, טלפון, כמה מוזמנים, צד". למי שצריך הזמנה באנגלית מוסיפים תא עם `en`. אחר כך לוחצים **שליחה ברצף**, או על כפתור הוואטסאפ ליד כל מוזמן. כל מוזמן מקבל קישור משלו: ההזמנה מברכת אותו בשמו, השם ומספר המוזמנים כבר ממולאים, ואתם רואים בדיוק מי צפה ומי ענה.
- **מישהו ענה בטלפון?** בלשונית **אישורים** לוחצים **הוספה ידנית**.
- **לאולם ולסידורי ההושבה**: **ייצוא לאקסל**, או **הדפסה** של רשימת האישורים.
- הכול נשמר גם בגיליון עצמו (כפתור הגיליון בראש לוח הניהול), כך שאפשר לסנן ולעבוד שם ישירות.

## תצוגה מקומית (למפתחים)

```bash
cd wedding
node tools/build.mjs          # צריך poppler-utils ו-ImageMagick
npx serve .                   # או כל שרת סטטי אחר
```

## פרטיות

- הדפים מסומנים כך שמנועי חיפוש לא יאנדקסו אותם (`noindex` ו-`robots.txt`).
- הנתונים נשמרים רק בגיליון שלכם בחשבון Google שלכם. לוח הניהול מציג אותם רק למי שיודע את הסיסמה, והבדיקה נעשית בצד השרת.
- מה שאורחים מקלידים נשמר בגיליון כטקסט בלבד, ולא יכול להפעיל נוסחאות.

## In English (short)

A small, fast website (not an app to install) guests open from a link: they see the invitation, RSVP with the number of guests in two taps, and share it on WhatsApp, Telegram or SMS. Everything they do lands in your Google Sheet and in a password-protected dashboard (`admin.html`). Both the guest page and the dashboard are fully bilingual: the **EN / עב** button switches language and text direction, `en.html` is the English link (with an English WhatsApp preview), and each invited guest can be set to Hebrew or English so their personal link and message arrive in their language.

Setup: edit `config.js` (every guest-facing text has `he` and `en`), replace `invitation.pdf`, paste `backend/Code.gs` into a Google Sheet's Apps Script (set `ADMIN_PASSWORD`, run `setup`, deploy as a Web app for "Anyone") and put the `/exec` URL in `backendUrl`. Then enable **Settings → Pages → Source: GitHub Actions** and merge to the default branch; the `Wedding site` workflow builds and publishes the site.
